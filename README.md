# Threads App Clone 💬🔥

A full-featured social media web application built with the **MERN stack**, offering real-time messaging, post sharing, and a seamless user experience.


## 🚀 Overview

Welcome to my **Threads App Clone**, a powerful full-stack web application inspired by modern social platforms. This project integrates real-time chat, social interactions, and responsive design — all built using the **MERN stack**, **Socket.io**, and **Chakra UI**. Designed to be scalable, intuitive, and user-friendly.


## 🎮 Features

- 🌟 **Tech Stack**: MongoDB, Express.js, React.js, Node.js, Socket.io, Chakra UI  
- 🔐 **Authentication & Authorization**: Secure login/signup using JWT  
- 📝 **Post Management**: Create, delete, like/unlike, and comment on posts  
- 👥 **User System**: Follow/unfollow users and view their activity  
- ❄️ **Account Control**: Freeze or deactivate your account at any time  
- 🌓 **Theme Toggle**: Switch between light and dark modes  
- 💬 **Real-Time Chat**:
  - Live messaging with image sharing  
  - Seen/unseen message tracking  
  - Sound notifications for new messages  
- 📱 **Fully Responsive**: Smooth performance across desktop, tablet, and mobile  
- 🚀 **Ready for Deployment**: Optimized for hosting on free platforms  


## 🛠️ Tech Stack

- **Frontend**: React.js, Chakra UI  
- **Backend**: Node.js, Express.js  
- **Database**: MongoDB (via Mongoose)  
- **Authentication**: JWT  
- **Chat**: Socket.io  
- **Image Hosting**: Cloudinary  


## ⚙️ Environment Setup

Create a `.env` file in your root directory and add the following variables:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret_key
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_cloudinary_api_key
CLOUDINARY_API_SECRET=your_cloudinary_api_secret 


## 🧪 Run the Application

### Install dependencies

```bash
npm install
```

### Build the app

```bash
npm run build
```

### Start the app

```bash
npm start
```
